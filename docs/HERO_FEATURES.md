# 🎨 Hero Section Features

## Visual Elements

### 1. **Animated Background**
- Gradient background with pastel pink tones
- Pulsing radial overlay effect
- Full viewport height (85vh)

### 2. **Floating Decorative Elements**
- 4 floating gem emojis (💎, ✨, 💍, 👑)
- Smooth floating animation
- Positioned at corners for balance

### 3. **Hero Content**
- **Sparkle Icon**: Rotating and scaling animation
- **Main Title**: "Nira Jewellery" with elegant typography
- **Subtitle**: Italic tagline with fade-in effect
- **Description**: Two-line description
- **CTA Buttons**: 
  - Primary: "Explore Collection" (black, ripple effect)
  - Secondary: "Contact Us" (outlined, hover fill)

### 4. **Scroll Indicator**
- Animated mouse scroll icon
- Bouncing animation
- Auto-hides on mobile
- Smooth scroll to products section

## Animations

1. **Pulse**: Background breathing effect (8s loop)
2. **Sparkle**: Icon rotation and scale (2s loop)
3. **FadeInUp**: Sequential content reveal (0.2s-1.5s delays)
4. **Float**: Gem elements floating motion (6s loop)
5. **Bounce**: Scroll indicator bounce (2s loop)
6. **Scroll**: Mouse wheel animation inside indicator
7. **Ripple**: Button hover effect

## Responsive Design

### Desktop (>768px)
- Full height hero (85vh)
- Large typography (4rem title)
- Side-by-side buttons
- Visible scroll indicator

### Mobile (≤768px)
- Reduced height (70vh)
- Smaller typography (2.5rem title)
- Stacked buttons (full width)
- Hidden scroll indicator
- Smaller floating gems

## Color Scheme

- **Background**: Gradient from #fde4ec → #F8C8DC → #fde4ec
- **Text**: Black (#000000)
- **Accents**: Pastel Pink (#F8C8DC)
- **Buttons**: Black with white text

## Typography

- **Font**: Segoe UI (system font)
- **Title**: 4rem, 300 weight, 4px letter-spacing
- **Subtitle**: 1.5rem, italic, 400 weight
- **Body**: 1.1rem, line-height 1.8

## User Experience

✅ Smooth scroll behavior
✅ Sequential content loading
✅ Interactive hover states
✅ Clear call-to-actions
✅ Mobile-optimized
✅ Accessibility-friendly
✅ Fast loading (no external assets)

- No JavaScript for hero animations
- No external images
